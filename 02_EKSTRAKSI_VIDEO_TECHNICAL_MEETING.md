### Slide 07 / 16: Technical Requirements
* **Timestamp:** 06:35 - 08:00
* **Judul:** Technical requirements
* **Sub-judul:** *"Teknologi bebas, tetapi AI Agent harus memiliki fungsi nyata dan dapat diakses publik."*
* **Spesifikasi Teknis:**
  * **Teknologi Bebas:** Bebas menggunakan LLM/API komersial maupun open-source (OpenAI, Gemini, Anthropic, open LLMs), framework agen (LangChain, LlamaIndex, kustom), atau low-code platform (n8n, Flowise). Sistem wajib diuraikan pada proposal.
  * **Fitur Lanjut Wajib (Minimal Memiliki 1 Fitur Aktif):**
    1. *Reasoning dan perencanaan langkah* (Multi-step reasoning & planning)
    2. *Integrasi API atau tool calling* untuk fetch data atau eksekusi aksi nyata
    3. *RAG (Retrieval-Augmented Generation)* untuk mencari dan menggunakan informasi dari basis pengetahuan/dokumen
  * **Deployment Publik:** Interface web AI Agent harus dapat diakses publik secara daring, disertai link demo live dan repositori GitHub publik (atau shareable workflow link).
* **LARANGAN KERAS (DILARANG):**
  * **Chatbot yang Hanya Membungkus API LLM ("ChatGPT Wrapper")**
  * Sistem yang hanya meneruskan user prompt ke model LLM tanpa kapabilitas reasoning terstruktur, tool calling, atau interaksi data eksternal **dinyatakan gugur / tidak memenuhi syarat**.

### Slide 13 / 16: Judging Criteria & Scoring Weight
* **Timestamp:** 11:40 - 12:55
* **Judul:** Judging criteria
* **Sub-judul:** *"Bobot resmi penilaian AI Agent dalam kompetisi GTNIC 2026."*
* **TOTAL 100% | 70% BOBOT TEKNIS PADA KEMAMPUAN AGENT:**
  1. **Kapabilitas dan Otonomi Agen (25%):** Kemampuan agen menyelesaikan pekerjaan secara independen dari input mentah hingga output final tanpa intervensi manual.
  2. **Penalaran, Perencanaan & Keputusan (15%):** Logika ReAct/planning dalam memecah tugas kompleks menjadi tahapan terstruktur.
  3. **Penggunaan Alat & Eksekusi Tindakan (15%):** Keakuratan pemilihan dan pemanggilan tool untuk mengambil data dan aksi sistem.
  4. **Arsitektur Teknis & Rekayasa Sistem (15%):** Kebersihan arsitektur, modularitas, guardrails terhadap error, dan keamanan.
  5. **Inovasi dan Kreativitas (10%):** Kebaruan pendekatan dibanding sistem otomasi konvensional.
  6. **Dampak Masalah dan Nilai Bisnis (10%):** Kuantifikasi nilai bisnis (penghematan jam kerja, biaya, dan penurunan error rate).
  7. **Pengalaman & Kemudahan Pengguna (5%):** Kemudahan penggunaan dashboard web, kejelasan status eksekusi agen.
  8. **Demonstrasi, Presentasi & Dokumentasi (5%):** Kerapian dokumen proposal dan kejelasan video walkthrough.
